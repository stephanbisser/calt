# Initialize CALT

A `.caltrc.json` lets you share rule severities, instruction-length thresholds, and
tenant defaults with the rest of your team.

Run **CALT: Initialize Config** from the Command Palette and pick a profile:

- **recommended** — sensible defaults
- **strict** — promotes warnings/infos to errors
- **security-first** — promotes OWASP LLM rules (SEC-*) to errors
